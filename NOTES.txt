# NOTES:  Other format ideas:

# Scientific Notation Format 🔬
🗿N 🔬=> 🗿(N×10^-E)e{E}_tons    WHERE E = floor(log10(N))

# SI Unit Format 📏
🗿N 📏=> 🗿{N}{SI_prefix}g    # Using strict SI prefixes (kg, Mg, Gg, etc)

# Comparison Format 🤔 (for human comprehension)
🗿N 🤔=> 🗿{N÷weight}_{object}s    # e.g. "equivalent to X elephants"

# Range Format 📊 (for approximations)
🗿N 📊=> 🗿{floor(N/10^k)}~{ceil(N/10^k)}_{unit}    # Shows magnitude range

# Mixed Unit Format 📝 (like imperial measurements)
🗿N 📝=> 🗿{B}_b_tons+{M}_m_tons+{K}_k_tons+{R}_tons    # Where B,M,K,R are calculated components
